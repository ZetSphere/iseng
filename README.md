## 🤔 Kenapa Harus Website Ini?

**Confess Anti Ditolak** adalah solusi digital interaktif buat kamu yang pengen nyatain perasaan dengan cara **unik, estetik, dan enggak garing**. Didesain khusus untuk bikin gebetan tersenyum, baper, dan mau tidak mau… **harus nerima kamu!** 😉

---

## ✨ Fitur Utama

* 🎨 **Mudah Dikustomisasi:** Sangat fleksibel untuk diedit teks, foto, maupun gayanya (HTML & CSS friendly).
* ⚡ **Ringan & Interaktif:** Efek interaksi tombol dan animasi visual yang mulus.
* 🌐 **Siap Deploy:** Bisa langsung di-host gratis ke **GitHub Pages**, **Vercel**, atau **Netlify**.
* 📱 **Responsive Design:** Tampil pas dan cantik di layar HP maupun Laptop/PC.

---

## 🛠️ Tech Stack

* **HTML5:** Struktur halaman dan konten.
* **CSS3:** Styling, tata letak, dan animasi interaktif.
* **JavaScript:** Logika tombol interaktif & *confessing trigger*.

## 🛠️ Cara Menggunakan

1. Clone repository dibawah ini:

   ```bash
   git clone [https://github.com/Madtch/Confession.git](https://github.com/Madtch/Confession.git)
   ```

2. Masuk ke folder project:

   ```bash
   cd Confession
   ```

3. Buka `index.html` di browser
4. Edit isi dan stylenya sesuai keinginanmu
5. Share link-nya ke dia… dan tunggu reaksinya
